Privacy Policy

Last updated: 15 November 2026

Roma Publisher is a private desktop tool used only by the owner of the YouTube channel Roblox ROMA.

What data it uses

With the owner's permission (Google OAuth), the tool uses the YouTube Data API, YouTube Analytics API and YouTube Reporting API to upload and schedule the channel's own videos, set their thumbnails, captions and playlists, post comments as the channel, and read the channel's own statistics.

Where data is kept

The access token and any downloaded statistics are stored only on the owner's own computer. Nothing is sold, shared with third parties or used for advertising.

Other people's data

The tool does not collect personal data about viewers or any other users.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. The tool's use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions: open an issue at github.com/Mytesla67/roma-publisher.
